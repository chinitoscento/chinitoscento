# Chinito Scento Terminology Standard

## Raw Materials Inventory Fields
* **SKU Code** (UI Label) $\rightarrow$ `sku_code` (Database Key)
* **Material Description** (UI Label) $\rightarrow$ `material_description` (Database Key)
* **Category** (UI Label) $\rightarrow$ `category` (Database Key)
* **UOM** (UI Label) $\rightarrow$ `uom` (Database Key)
* **Available Stock** (UI Label) $\rightarrow$ `available_stock` (Database Key)
* **Avg Cost / Unit** (UI Label) $\rightarrow$ `avg_cost_unit` (Database Key)
* **Status** (UI Label) $\rightarrow$ `status` (Database Key)
